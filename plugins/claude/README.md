# Claude Code plugin

This repo *is* the plugin. From a checkout:

```bash
claude plugin marketplace add .
claude plugin install jev-integrate@jev-integrate
```

Or from GitHub after it is pushed:

```bash
claude plugin marketplace add pruthvirajg/Jev-Integrate
claude plugin install jev-integrate@jev-integrate
```

Set `TYPESAFE_API_KEY`. Hooks fail open without it.
